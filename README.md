# Módulo financeiro — DW3

## Objetivo do trabalho

Trabalho acadêmico da disciplina Desenvolvimento Web 3. O objetivo é criar um sistema cliente-servidor para gerenciar o plano de contas e as contas a pagar de uma cooperativa, com autenticação, operações CRUD e armazenamento no PostgreSQL.

## Tecnologias

Node.js, Express, Nunjucks, PostgreSQL, HTML, CSS e JavaScript.
